# Глобальная команда selfsteal

Канонический комплект для личной установки в Codex:

- `skills/selfsteal/` → `C:/Users/User/.codex/skills/selfsteal/`.
- `global-rules/selfsteal.md` → добавить в `C:/Users/User/.codex/AGENTS.md`,
  сохранив существующие правила. Не заменять весь глобальный файл этим фрагментом.

После проверки и публикации GitHub-состояния скопировать каталог навыка,
добавить правило ровно один раз, проверить совпадение файлов. При обновлении
проверить локальные отличия и сохранить резервную копию до замены. Не копировать
глобальные секреты или весь пользовательский конфиг обратно в репозиторий.

`/selfsteal` — текстовый псевдоним для агента, **не регистрация встроенной
slash-команды в меню**. Нативное упоминание навыка: `$selfsteal`. Новые глобальные
инструкции проверять в новой задаче/сессии; если навык не обнаружился,
перезапустить Codex.

```text
/selfsteal
Сервер: <название>
IP: <подтверждённый входной IPv4>
SSH: <алиас или путь к ключу>
Домен: <поддомен>
DNS: <путь к токену либо ручная запись>
Сайт: Ремонт чайников
```

Можно отправить только `/selfsteal`: агент запросит недостающие данные.
При обычной установке VPN-ноды правило предлагает «self-steal: да / нет».
Явный ответ или вызов навыка не требует повторного выбора. Существующие ноды
не изменяются от самой установки навыка. Учётные данные в комплекте отсутствуют.

## Проверки

```text
python -X utf8 -m unittest discover -s codex/tests -p test_*.py -v
python -X utf8 -m unittest discover -s ops/selfsteal-us3 -p test_*.py -v
python -X utf8 <skill-creator>/scripts/quick_validate.py codex/skills/selfsteal
```

Рендерер работает офлайн и возвращает только публичные шаблоны в JSON:

```text
python -X utf8 codex/skills/selfsteal/scripts/render.py --hostname de5.example.com --ipv4 203.0.113.20
```

IP в примере документационный. Шаблоны требуют инвентаризации, проверки nginx
на целевой ОС и адаптации под сетевой namespace Xray. По умолчанию это nginx
на Debian/Ubuntu с systemd, certbot webroot `/var/www/acme` и каталогом сертификата
по имени домена. Проверить фактическое имя сертификата (оно может иметь суффикс)
и наличие/пути команд перед использованием. Для другой темы сайта изменить
не только заголовок, но и текст: исходный шаблон — о ремонте техники.

Тесты проверяют параметры, изоляцию публичного VPN-порта, DNS, TLS-шаблоны,
экранирование, статическую страницу, контраст и отсутствие сетевых действий
у рендерера. Они не заменяют nginx/Xray configuration test, выпуск сертификата
и реальную VPN-пробу при каждом будущем развёртывании.
