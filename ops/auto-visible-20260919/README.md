# Автовыбор из обычных хостов

Пользователь выбрал: автоматические пулы используют только обычные хосты,
доступные абоненту по его тарифу. Скрытые кандидаты без обычной пары исключаются;
права обычных хостов не расширяются. Это изменение состава пула, а не изменение
VPN-протоколов, маршрутов серверов или параметров DPI-маскировки.

`migration.py` выполняется на панели из опубликованного Git-коммита.
`prepare` сверяет пары и сохраняет закрытый снимок API и полный дамп PostgreSQL.
`candidate` получает реальные подписки временного технического пользователя
для BASE, WHITE, OLD, TEST и BASE+WHITE и строит кандидат штатными генераторами
установленной Remnawave. Полные конфиги и реквизиты остаются только в закрытом
каталоге `/root/ham-auto-visible-20260919` или памяти процесса.

`apply` переносит метки пулов на обычные хосты, устанавливает Xray
`selectFrom: NOT_HIDDEN`, отключает `includeHiddenHosts` в Mihomo, обновляет
фильтр ПК-группы и временно отключает скрытые записи. Изменения защищены
20-минутным независимым таймером отката. Состав прав сквадов, профили нод,
параметры подключения и порядок обычных хостов проверяются на неизменность.

`public` проверяет фактическую выдачу после применения. Кандидат и публикация
проверяются полными конфигами Xray/mihomo: запуск ядра, состав URL-test группы,
URL-test, три HTTPS-запроса и публичный выходной IP. Клиенты запускаются отдельно
от пользовательского приложения; его TUN и настройки не меняются.

Только `finalize` после успешной проверки отключает таймер, удаляет скрытые
записи, повторно проверяет выдачу BASE и удаляет технического пользователя.
До `finalize` доступен откат через `rollback`; после удаления записи можно
восстанавливать только из закрытого резервного снимка/дампа с отдельной сверкой.
Нельзя восстанавливать весь дамп поверх новых пользовательских данных.

Удаление не превращает старые недоступные адреса в работающие. Периоды проб,
стратегия leastLoad, TTL, TLS/REALITY и ядра VPN-нод не меняются. Для подключения
нового обычного хоста к ПК-пулу необходимо обновить соответствующий фильтр
Mihomo; Xray выбирает участников по меткам `AUTO_BASE_POOL`/`AUTO_WHITE_POOL`.

## Подтверждённый результат 19 сентября 2026

Миграция применена из коммита `fe0289d16512724437f13d7b057ea8cf3e5af554`.
Удалены 27 скрытых записей; в панели осталось 34 обычных хоста. Метки
перенесены на 18 соответствующих обычных записей; восемь кандидатов без пары
исключены. В основном пуле 17 обычных хостов, ограниченных правами подписчика.

Проверены реальные выдачи BASE, WHITE, OLD, TEST и BASE+WHITE до и после
применения. TEST сохранил служебную заглушку: доступных хостов у него нет.
Полный основной конфиг Xray и полный конфиг mihomo запущены в изолированных
процессах: URL-test mihomo, по три последовательных HTTPS-запроса и получение
публичного выходного IP успешны. Это серверная проверка клиентскими ядрами;
проверку с iPhone в сети российского оператора она не заменяет.

Запись управления существующей нодой «Нидерланды 3» перенесена со скрытого
дубля на обычный хост с сохранением идентификатора и прямого режима.
Настройки 30 нод, 24 профилей и прав сквадов сверены с исходным снимком.
После удаления повторно проверена выдача BASE, технический пользователь
удалён с проверкой 404, таймер отката отключён. Панель и сервис инфраструктуры
здоровы. Локальные проверки: 58 Python-тестов, Ruff и синтаксис render.cjs.
