## Germany #650 (former VLESS TLS — 245)

The existing SSH reverse service could remain active while its entry-side TCP
queue stopped progressing. Paramiko's old keepalive did not require a reply.
Commit `54e0bca0f65c082ad5cdc3513fd05336877325a5` adds a 15-second
acknowledged health request with a 15-second response deadline; on failure the
transport closes and the existing supervisor reconnects after five seconds.
Only the operation-owned reverse service was upgraded. Node/host names, legacy
inbounds, customer identities, panel configuration and firewall were preserved.

One automatic reconnect was observed after the repair. The replacement
connection was moving payload in both directions at the later check. This is
recovery from a stalled connection, not proof that the underlying network
stopped dropping traffic. The root cause of those network drops is not proven.

Post-recovery real Happ main and auto subscription tests both returned HTTPS
204 and egress `196.251.107.245`. Six additional tests passed: public Chrome and
Firefox, main and auto candidates, cached legacy REALITY and cached legacy TLS.
The user independently confirmed sites open from the affected client network.
Frontend configuration SHA256 remained
`4fc2f364ebfdc726f9a7ad56a482fc9c1d9628063574c1b67bc93b28d99ba2c0`.
The previous service unit is preserved in the root-only reverse state directory
as `unit-before-ack-health.conf`.

## Kazakhstan 2

No client hosts or VPN profile were switched. No WireGuard was installed.
The completed, authenticated UDP exchange on port 54433 showed:

- CLOUDru → Kazakhstan: 12 datagrams sent; Kazakhstan listener received zero.
- Kazakhstan → CLOUDru: CLOUDru received all 12 authenticated datagrams and
  attempted all 12 equal-sized replies; Kazakhstan received zero replies.
- Sizes tested: 64, 512 and 1200 bytes, four datagrams per size.

Thus this test did **not** establish a usable two-way UDP path. It does not
prove every UDP port is blocked. The port-54434 exchange was incomplete and is
not counted as a valid second-port failure.

The bounded listeners exited. The exact source-restricted temporary firewall
chain/jump were removed; rollback timer and service were confirmed inactive
with successful results. Four temporary probe secret records were removed;
non-secret diagnostic evidence and protected firewall snapshot are retained.
