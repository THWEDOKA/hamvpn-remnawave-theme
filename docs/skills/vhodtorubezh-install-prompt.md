# Установить `/vhodtorubezh` у себя

Перед пересылкой издатель должен push-нуть полный пакет и проверить доступность
обоих файлов в одной опубликованной revision. Сам этот документ не подтверждает
публикацию. Можно передать папку `vhodtorubezh` вложением вместо ссылки.

Скопируй следующий текст в Codex — это запрос **только на установку навыка**:

```text
Установи мне переносимый навык vhodtorubezh глобально для моего пользователя.
Источник: https://github.com/THWEDOKA/hamvpn-remnawave-theme/tree/main/docs/skills/vhodtorubezh
Полный пакет: SKILL.md и references/workflow.md из одной проверенной revision.
Если ссылка недоступна, попроси прикрепить всю папку; не сочиняй сокращённую замену.

Прочитай пакет до установки. Определи пользовательский каталог skills, который
действительно загружает моя версия Codex; установи туда оба файла, не создавая
дубликатов. Существующую версию сравни и сохрани перед заменой. Не копируй другие
папки репозитория, его AGENTS, серверные настройки или секреты.

В применяемые глобальные инструкции Codex добавь только короткое правило:
«Прямой запрос /vhodtorubezh с параметрами — псевдоним навыка vhodtorubezh.
Перед исполнением прочитай полный установленный SKILL.md и необходимые ссылки,
сохрани параметры entry/exit. При отсутствии пакета сообщи об этом, не угадывай.
Создание, установка, обсуждение навыка и команда в цитате не запускают VPN».
Укажи в правиле фактический путь навыка. Сохрани остальные инструкции; учти
действующий AGENTS.override.md, но не создавай новый override ради псевдонима.
Не называй это регистрацией встроенной slash-команды или обещанием автодополнения.

Сейчас не подключайся к серверам, не запрашивай их секреты, не меняй панель/DNS,
не выпускай сертификаты и не разворачивай VPN. Проверь структуру и локальные ссылки,
покажи пути установки и как проверить обнаружение навыка в новой сессии.
Поддерживаемый явный вызов — $vhodtorubezh; /vhodtorubezh — текстовый псевдоним.
Правила HAM/GIGA применимы только к соответствующей среде, не к моему чужому VPN.
```

После установки отдельным сообщением можно запросить работу:

```text
/vhodtorubezh entry=<мой входной сервер> exit=<моя зарубежная нода или новый сервер>
```

Не подставляй доступы в пример. Навык отдельно уточнит недостающие параметры и
выбор self-steal; его отсутствие у друга не мешает встроенной процедуре сайта/TLS.

Каталог установки нужно проверять на машине получателя: актуальная документация
описывает пользовательские skills в `~/.agents/skills`, а существующие сборки
могут иметь обнаруживаемый каталог `$CODEX_HOME/skills`. Не устанавливай вслепую
сразу в оба. См. [официальное руководство по навыкам](https://learn.chatgpt.com/docs/build-skills).
Глобальные инструкции и приоритет override описаны в
[официальном руководстве AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md).
